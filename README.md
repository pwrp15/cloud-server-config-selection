# 云服务器配置怎么选：先按用途定CPU、内存和带宽，再挑地域线路，附全套餐价格对照

购买页面上那一串下拉框——区域、CPU 型号、套餐档位、带宽、云盘、IP 数量——第一次打开确实容易发懵。选高了每月多花几十上百，选低了网站一上量就卡，或者半个月后才发现流量额度见底。

多数人把顺序搞反了。配置不是挑出来的，是倒推出来的：先想清楚这台机器要干什么、谁来访问、准备付多久的钱，参数才会收敛成唯一答案。

## 第一步：三个问题先答完，参数自动缩小范围

**这台机器用来做什么。**

- 博客、作品集、测试环境：并发低，CPU 和内存压力小，真正影响体验的是打开速度和线路质量；
- 企业官网、小程序后端、小型电商：怕的是数据库拖后腿和高峰期崩，稳定优先；
- 游戏服（Minecraft、幻兽帕鲁这一类）：吃单核主频和物理距离带来的延迟，核心堆多了纯属浪费；
- 云电脑、远程桌面：CPU、内存、带宽、延迟四项都要及格，缺一项就难受。

**访问者在哪里。** 用户在国内，国内机房延迟能压到几十毫秒；主要面向东南亚或日本，香港、东京更近；只想免备案、面向海外，洛杉矶是常规选择。

**准备付多久的钱。** 云厂商的折扣几乎都押在长周期上。雨云的规则是季付 9 折、半年付 8 折、年付 7 折，年付省下来的钱经常相当于多送你两三个月。反过来，临时跑个测试就没必要买一年。

## CPU：核数是第一层，型号和主频是第二层

“2 核”这个数字本身不说明性能。同样 2 核，一颗 2.2GHz 的 E5 v4 和一颗 3.7GHz 以上的 EPYC 7A23，跑单个 PHP 请求的差距是能感知到的。

看用途分两条路：

- **并发型任务**（网站、API、多容器）看核数。核多意味着能同时处理的请求多，单核慢一点问题不大。
- **单线程敏感型任务**（Minecraft、部分老游戏服务端、编译）看主频和单核跑分，核数多反而拉高成本。

另外注意**独享还是共享**。共享型实例在物理机上和其他用户抢 CPU，闲时没感觉，晚高峰就抖。同价位的机器，如果官方明确写了独享资源，通常更值。

粗略的档位参考：

| 核数 | 大致能扛什么 |
| --- | --- |
| 1 核 | 个人博客、静态站、学习练手、跑单进程脚本 |
| 2 核 | 中小型网站、带数据库的 CMS、轻量 API |
| 4 核 | 多站点、中等流量电商、论坛、带缓存的数据库 |
| 8 核及以上 | 多实例集群、数据处理、游戏服群组 |

雨云的云服务器可选 Intel Xeon E5 v4、Xeon Gold、Xeon Platinum 以及 AMD EPYC 7K62/7702、Ryzen、i9 等不同平台，同一档配置换 CPU 型号价格会变，这也是它页面看着复杂的原因。

## 内存：最容易被估错的一项

内存不够时系统会动用 swap，用硬盘顶内存，性能直接断崖，而且你很难第一眼看出问题在哪。

把需求拆成四块：系统本身、面板（宝塔/1Panel 这类）、Web 应用、数据库。Linux 精打细算 512MB 能跑，但加个宝塔面板就紧张；MySQL 的缓冲池想吃掉 1~2GB；PHP-FPM 的子进程每个 20~40MB，配 20 个就是几百兆。

落到档位上：

- **1GB**：纯静态站、练手、跑单进程服务，能省则省的场景；
- **2GB**：WordPress + 数据库的稳妥起点。注意 **Windows 系统本身占用就大，建议 2GB 起步**；
- **4GB**：插件多、多站点、带 Redis 缓存，或日均几千到上万 PV；
- **8GB 以上**：多应用并行、较大数据库、Java 应用、游戏服。

顺便说一句，内存的余量比 CPU 的余量更值得留。CPU 跑满只是变慢，内存跑满会直接连不上。

## 带宽和流量：别只盯着 Mbps 的数字

带宽的单位是 Mbps，实际下载速度要除以 8：

| 带宽 | 理论峰值下载速度 | 大致对应场景 |
| --- | --- | --- |
| 1 Mbps | 约 128 KB/s | 测试站、极小博客 |
| 2 Mbps | 约 256 KB/s | 个人博客 |
| 5 Mbps | 约 625 KB/s | 企业官网、小型 CMS |
| 10 Mbps | 约 1.25 MB/s | 普通内容站 |
| 30 Mbps | 约 3.75 MB/s | 有一定并发的业务站 |
| 100 Mbps | 约 12.5 MB/s | 图片站、下载站、高流量站 |

这是理论峰值，实际还要扣掉线路损耗、协议开销和用户端的网络状况。所以估算时留一倍余量比较稳：一个页面 1MB，同时 20 个人打开，10Mbps 就已经吃满了。

**流量模式比带宽数字更值得看清。** 雨云把方案分成两类：

- **流量叠加型**（大带宽 + 每月固定流量）：带宽给得高，适合短时间大量下载、备份、分发；本月没用完的流量可以累积到下月，超出后限速，可以加购流量包恢复高速；
- **流量不限型**：带宽相对小一点，适合长期稳定跑站，不用担心月底突然限速。

> 同一个配置，选“叠加型”还是“不限型”价格可能一样，但网速和超量后果完全不同。下单前确认页面上写的是哪一种。

## 硬盘：系统盘能省，数据库盘不能省

雨云的云服务器系统盘默认 30GB 左右起步，购买后可以弹性扩容，按天计费，机房和云盘类型不同单价也不同——这一点上各家官方价格页基本一致：扩容比重新买一台划算，但成本会随使用时间累积。

三条经验：

1. **数据库和缓存必须放 SSD。** 机械盘便宜，随机读写撑不住数据库。
2. 雨云社区里一句被反复提到的话：不是开网站的话，别用机械盘。反过来，纯粹放大文件、做备份，机械盘是真省钱。
3. 30GB 装系统 + 宝塔 + 几十张图就七八成满了，建议一开始就给到 50GB 以上，避免后期搬数据的麻烦。

## 地域和线路：延迟、备案、防御，三选优先级

这一步经常被忽略，但对体验的影响比多一核 CPU 大得多。

| 机房类型 | 特点 | 适合谁 |
| --- | --- | --- |
| 江苏宿迁、重庆电信等国内节点 | 延迟低，部分带高防，国内节点需要备案 | 面向国内用户的正规站点 |
| 浙江宁波、绍兴、温州 | 大带宽、部分带 100G 高防 | 下载站、高流量业务、游戏服 |
| 中国香港 | 免备案，三网优化线路延迟较低 | 想省备案流程的中文站点、跨境起步 |
| 美国洛杉矶 | 免备案，带宽大，延迟偏高 | 海外用户、面向全球的业务 |
| 日本东京、韩国首尔、德国法兰克福 | 就近覆盖区域用户，首尔有直连线路 | 面向日韩、欧洲的业务 |

免备案节点（香港、洛杉矶等）适合想快速上线、又不想走备案流程的项目。反过来说，如果业务本身需要国内合规资质，备案是绕不开的，早做比晚做省事。

## 三套可以直接照着买的配置

**个人博客 / 作品站 / 学习练手**

2 核 2GB、系统盘 30GB 够用，带宽看访问量：日均几百 IP 用 5Mbps 左右足够，如果以后打算放图，直接上大带宽 + 流量叠加型更从容。这一档的月付价基本在 30 元上下。

**企业官网 / 小程序后端 / 小型电商**

4 核 4GB 起步，数据库单独吃 SSD，带宽 30Mbps 以上。国内用户为主就选带备案的国内节点，想免备案就走香港。这一档的月付价通常在 60~70 元区间，年付 7 折后折合每月四五十元。

**Minecraft 或同类游戏服**

优先高主频 CPU，而不是高核数。4 核 8GB 配 15Mbps 上行是能开得比较舒服的配置，同时把延迟放在第一位——玩家和服务器之间的物理距离，是后面加钱也补不回来的东西。

## 下单前最容易踩的四个坑

1. **只比首年价，不看续费价和附加项。** 公网 IP、硬盘扩容、流量包、高防 IP 都可能是单独计费的，这些加起来的月度成本有时比主机本身还高。
2. **只写“几核几G”，不写 CPU 型号和是否独享。** 同价位的机器，共享型在高峰期会明显掉速。
3. **把“共享带宽”当成独享。** 页面写 100Mbps、1Gbps 的时候，先确认是独享端口还是共享端口。
4. **忽略流量模式。** 不限流量和流量叠加型是两种产品逻辑，买错方向的后果通常是月底被限速。

## 几个常被问到的问题

**1 核 1G 到底能不能跑网站？**

能。纯静态站、访问量很小的个人博客完全没问题，配宝塔面板也能跑，只是别指望同时挂多个站点或者跑数据库密集的业务。

**年付一定比月付划算吗？**

如果你的项目会跑一年以上，是。但如果只是验证一个想法，先用 5 折首月券或者 1 元试用跑一个月，比一次性付一年更安全——这也是雨云 7 天无理由退款之外的第二层保险。

**国内节点和香港节点怎么选？**

要合规、要最低延迟，选国内；要免备案、要快速上线，选香港。两边价格差距不大，真正决定体验的是目标用户在哪里。

**配置买小了怎么办？**

雨云支持购买后按天补差价升级套餐、扩容云盘、迁移地区，所以“先买小的，不够再升”是可行路线。前提是别忘了硬盘和内存这类不方便临时大改的部分，一开始就留出余量。
